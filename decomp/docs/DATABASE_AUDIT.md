# MHFU database initial accuracy audit

The clean [mhfu-db checkout](https://github.com/Kolyn090/mhfu-db) at `98144e264350d6dcd0db25ba7c27eded49838547` contains 61 tracked JSON files and 11,070 records. All files parsed as arrays. The [machine inventory](output/audit/repository-inventory.json) records every nested property path, observed JSON type and occurrence count, top-level key order variants, and each input file's SHA-256. In schema paths, `*` denotes an array element and the empty path denotes the document root.

The audited binary is the North American English archive, ULUS10391 v1.01. The old index reader interpreted ciphertext as sector pointers. The shared decoder now deciphers the index and reads 6,657 entries. See [binary structures and evidence](BINARY_SOURCES.md) and [regional differences](REGION_DIFFERENCES.md).

## Results available for review

- **Items.** The English text pack exposed 1,260 non-dummy IDs. Of 1,259 public rows, 1,226 had a unique exact name on both sides and a whitespace-normalized description match. Thirteen unique names had a description discrepancy, sixteen names had no exact match, and four rows had ambiguous names. [Item comparison](output/audit/item-comparison.json) includes original and decoded descriptions for discrepancies and all unresolved ID candidates. The [separate items.json proposal](output/audit/proposals/items.json) adds integer IDs to the 1,226 verified rows. It retains every original key, value, image reference, JSON type and row position.
- **Quests.** The audit decoded 551 archive payloads and verified every NA/EU salted SHA-1. Of 555 public rows, 235 link to one archive record by title and goal, with exact details and client used to narrow repeated pairs where available. Each accepted binary record had a single public claimant. Of those links, 229 agree across the fields compared, and six have discrepancies. The Silver Horn (10308) lists 20 minutes in the database and 50 in the payload. The Approaching Gaoren (1218) lists a 100z fee in the database and 1,000z in the payload. The remaining 294 public rows have ambiguous matches and 26 lack an exact title/objective pair. There are 316 unlinked binary records, including repeated and placeholder payloads. The [quest comparison](output/audit/quest-comparison.json) has row-level evidence, old and decoded values, and unresolved candidates. Folder assignment, special conditions, difficulty, and displayed monster lists remain open even for linked records.
- **Maps and gathering.** The existing gathering extract's 551 quest headers and 351 item names agree with fresh binary reads. It contains 19,995 spot rows across 29 quest map variants, including 865 fish-spawn spots. Of 6,460 public map material references, 6,344 have an exact English game item name and 116 require review. Those counts measure spelling and identity only. The 21 public location records still need a verified map, area, and rank crosswalk before loot membership can be judged. [Gathering cross-check](output/audit/gathering-crosscheck.json)
- **Cross-file references.** The [reference report](output/audit/name-references.json) checks item notes, recipes, map materials, equipment ingredients, weapon upgrades, monster tables, and quest monster names. Each exception includes a JSON Pointer. Duplicate names are reported as ambiguous. All 139 note names match exactly one English item. Two of 516 recipe name references lack an exact English item match. These tests establish name relationships only.

Comparison row numbers start at zero. Text checks collapse whitespace and retain case, punctuation, and control codes. Quest title and objective matches support individual links. Menu membership needs separate evidence from the game. Attributions include game observations and community references, so the next steps use the binary or runtime routine to verify gameplay values. [Repository attributions](https://github.com/Kolyn090/mhfu-db/blob/main/Attributions.txt)
